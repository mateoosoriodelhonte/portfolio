# mateo-portfolio

Personal portfolio of **Mateo Osorio Delhonte** — software engineer building reliable systems,
developer tools, and grounded AI.

> Work in progress toward v1.0. Full documentation (architecture, design system, deployment)
> lands with the first release.

## Stack

Astro 7 · TypeScript · Tailwind CSS 4 · MDX · Playwright · GitHub Actions

## Local development

```bash
npm install
npm run dev
```

The site runs at `http://localhost:4321/portfolio` (the base path matches the GitHub Pages
deployment).
